# Portfolio Page

A simple, static personal page built with plain HTML and CSS — no frameworks, no build step.

Open `index.html` in a browser to view it. The page summarises my education, experience, and skills from my CV, and links to my LinkedIn and GitHub profiles.

## Files

- `index.html` — the page content
- `style.css` — the page styling

## What this demonstrates

- Semantic HTML structure (headings, sections, lists)
- Clean, readable CSS for layout and spacing
- A page that works without JavaScript or external dependencies
